# STEP 5 — Create Feature Layers

These are ML input variables.

---

## A. NDVI

Vegetation index.

Formula:

NDVI = \frac{NIR-Red}{NIR+Red}

Meaning:

* high NDVI → vegetation
* low NDVI → urban/bare land

---

## B. NDBI

Built-up index.

NDBI = \frac{SWIR-NIR}{SWIR+NIR}

Meaning:

* high NDBI → urban areas

---

## C. Elevation

Usually from DEM.

Dataset:

```javascript
USGS/SRTMGL1_003
```

---

## D. Slope

Derived from elevation.

Important because cities usually expand on flatter areas.

---

## E. Other Possible Features

Optional:

* temperature
* distance to roads
* population density
* distance to city center
* land surface temperature

# STEP 17 — Load CSV

Example:

```python
import pandas as pd

train = pd.read_csv("training.csv")
```

---

# STEP 18 — Select Features & Labels

Example:

```python
X = train[['NDVI','NDBI','Elevation','Slope']]
y = train['Class']
```

---

# STEP 19 — Split Dataset

Example:

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3
)
```

---

# STEP 20 — Train ML Model

Usually:

* Random Forest
* SVM
* Decision Tree
* XGBoost

Best beginner choice:

## Random Forest

Example:

```python
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier()
model.fit(X_train, y_train)
```

---

# STEP 21 — Evaluate Model

Metrics:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

Example:

```python
from sklearn.metrics import classification_report

pred = model.predict(X_test)

print(classification_report(y_test, pred))
```
